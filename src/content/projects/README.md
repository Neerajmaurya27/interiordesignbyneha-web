# Projects

One folder per completed project: `src/content/projects/<slug>/index.md` with its images beside it,
named `<slug>-<nn>-<room>-<orientation>.jpg` (masters 2560–3200px, sRGB). The frontmatter schema
is in `src/content.config.ts`.

A project reaches production only when `published: true` **and** `verified.facts` and
`verified.credits` are true. Real photographs of completed work only; concept renders must be
captioned "Concept visualisation".
